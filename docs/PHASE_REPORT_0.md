# تقرير المرحلة 0 — الأساس (Foundation)
**المشروع:** MIDAD — مِداد · Teacher Workspace  **التاريخ:** 2026-09-29

## 1) الخلاصة
تم بناء هيكل المشروع كاملًا (Flutter + FastAPI + PostgreSQL + Drift) مع نظام التصميم، الترجمة (AR/FR/EN)، التوجيه، بنية الأخطاء، مخطط قاعدة البيانات، الـ migration، Docker، CI، والاختبارات الأولية. **لا توجد ميزات وظيفية بعد** (تسجيل الدخول، الحضور، العلامات… تبدأ في المرحلة 1)، والشاشات غير المبنية تظهر بوضوح كـ«متاح في المرحلة X» بدون بيانات وهمية.

## 2) ما تم إنجازه
**الشعار والهوية**
- استُخدم الشعار المرفق: `assets/brand/midad_logo_full.png` (كامل) و`midad_mark.png` (الرمز فقط، مربّع) — الأخير يُستعمل في شاشة Splash وأيقونة التطبيق (`flutter_launcher_icons`).
- ألوان العلامة مأخوذة من الشعار: `#7B1737` (أساسي)، `#4E0A22`، `#F6D5DC`.

**Backend (FastAPI)**
- `core/`: config (يرفض أسرار ضعيفة في الإنتاج)، database (معاملة واحدة لكل طلب)، security (Argon2id + JWT access/refresh بأسرار منفصلة + hash للـ refresh token)، logging (JSON)، exceptions (غلاف أخطاء موحّد + أكواد: NETWORK/AUTH/VALIDATION/CONFLICT/PERMISSION/FILE… بدون تسريب stack traces).
- `main.py`: CORS من الإعدادات، security headers، Request-Id، إخفاء /docs في الإنتاج، `/api/v1/health` و`/api/v1/health/ready`.
- `shared/deps.py`: `Principal` + `current_principal` (أساس التفويض).
- 19 وحدة (modules) بنفس هيكل المواصفات.
- **مخطط PostgreSQL كامل (~40 جدولًا)** مع UUID، created/updated_at، `version`، soft-delete، FK، unique، CHECK، فهارس؛ + `refresh_tokens` و`audit_logs` (append-only مع before/after). **لا توجد أي جداول AI.**
- Alembic: `0001_initial_schema` (baseline) قابل للتراجع.
- اختبارات: security، API foundation (لا تسريب أخطاء)، schema (كل الجداول المطلوبة، لا جداول AI، كل جدول يخص معلمًا فيه `teacher_id`).

**Mobile (Flutter)**
- نظام التصميم المركزي: AppColors/Typography/Spacing/Radius/Shadows/Icons/Animations/Theme (فاتح/داكن/نظام).
- الترجمة: `app_ar/fr/en.arb` (19 مفتاحًا متطابقة في اللغات الثلاث — تم التحقق) + RTL/LTR ديناميكي.
- التوجيه (go_router) مع قاعدة redirect نقية مُختبَرة، Splash بالشعار، تنقل سفلي: الرئيسية/الحصص/المخطط/التحليلات/المزيد (بدون تبويب AI)، وزر «+» (معطّل عمدًا حتى المرحلة 2).
- صفحة «المزيد» فيها مبدّل اللغة والوضع فقط (للتحقق من RTL/Dark).
- بنية الأخطاء: `AppError` + `mapError` (Dio → رمز منظّم) + رسائل مترجمة ومحايدة.
- **مخطط Drift المحلي:** `sync_queue` (بالحقول المطلوبة + CHECK للحالات) وجداول الأكاديمية/الحصص/الطلاب/الحضور/التقييمات/النتائج/audit، كلها بأعمدة مزامنة (`version`, `syncStatus`, `deletedAt`).
- اختبارات: redirect، error mapper، قاعدة البيانات، smoke (RTL ↔ LTR).

**DevOps/وثائق:** docker-compose (postgres + redis + backend)، `.env.example`، `.gitignore`، CI (GitHub Actions)، README، `docs/ARCHITECTURE.md` (بروتوكول المزامنة والتفويض)، `docs/ROADMAP.md`، `tools/bootstrap_mobile.sh`.

## 3) حالة التحقق — بصراحة
بيئة العمل هنا **بدون إنترنت وبدون Flutter/Docker/PostgreSQL**، لذلك:
- ✅ تم: فحص صياغة كل ملفات Python (`py_compile`)، تطابق مفاتيح ARB، فحص بنية الملفات.
- ❌ **لم يُشغَّل بعد:** الاختبارات (pytest/flutter test)، `alembic upgrade`، `flutter analyze`، `build_runner`، Docker.
لهذا **بوابة التحقق ليست مكتملة**. على جهازك شغّل:
```
docker compose up --build            # ثم: curl localhost:8000/api/v1/health
cd backend && pip install -r requirements-dev.txt && pytest -q
bash tools/bootstrap_mobile.sh       # يُنشئ android/ios، يولّد الكود، analyze + test
```
أرسل لي أي خطأ يظهر وأصلحه قبل/أثناء بداية المرحلة 1. (متوقع وجود أخطاء بسيطة لأن الكود لم يُترجَم بعد.)

## 4) قرارات وانحرافات عن المواصفات
1. **اللون:** الشعار والتصاميم المرفقة بورغندي، بينما المواصفات تعتمد #101828 وأزرق. اعتمدت البورغندي كلون العلامة (أزرار، FAB، العنصر المحدّد) وأبقيت ألوان المواصفات للنصوص/الخلفيات/الحالات والرسوم. يمكن عكس ذلك بتغيير سطر واحد.
2. **شاشة «المساعد الذكي» في التصاميم المرفقة** (والزر ✦) **لم تُنفَّذ**: المواصفات تمنع الذكاء الاصطناعي في النسخة 1. سأستخدم تصاميمك للشاشات الأخرى (الرئيسية، تفاصيل الحصة، الحضور، التحليلات) مع أيقونة «+» عادية بدل ✦.
3. **Migration الأول** يعتمد `create_all` كـ baseline؛ كل migration لاحق سيكون صريحًا.
4. **الخطوط** (Tajawal/Inter) معرّفة بالاسم لكن ملفاتها غير مضمّنة (لا إنترنت هنا). ضعها في `mobile/assets/fonts` وسجّلها في pubspec (مطلوب للعمل دون اتصال).
5. مجلدات `android/` و`ios/` تُولَّد بـ `flutter create` عبر السكربت.
6. `MIDAD_DEV_SKIP_AUTH` علم تطوير مؤقت لرؤية الواجهة قبل المرحلة 1؛ الافتراضي: بدون جلسة → شاشة تسجيل دخول «قيد الإنشاء».
7. قيد «العلامة ≤ الحد الأقصى» عبر جدولين يُطبَّق في الخدمة + trigger في المرحلة 1 (لا يمكن كـ CHECK).
